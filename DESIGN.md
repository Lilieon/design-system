# DESIGN.md

Lilian's design system — the visual language shared by all my websites and web
applications. This file is read by humans and by AI coding agents: when you
(AI agent) build or modify UI in one of my projects, follow every rule in this
document. It complements `AGENTS.md` (how to build) by defining how the product
must look and feel.

Stack: Angular (standalone components) + Tailwind CSS v4. All visual values
come from design tokens (W3C DTCG format) built to CSS custom properties.

## Identity

- **Feel**: precise, calm, professional. Close to Linear/Vercel-grade polish —
  quiet surfaces, strong typography, restrained color, subtle depth.
- **Voice**: direct sentences, sentence case, no exclamation marks.
- **Density**: comfortable-first; compact variants exist but never at the cost
  of touch targets (minimum 40px interactive height).

## Principles

1. **Tokens only** — never hardcode a color, spacing, radius, shadow, duration
   or easing. Use the semantic CSS variables listed below or their Tailwind
   utilities (`bg-primary`, `text-muted-foreground`, `border-border`, …).
2. **Hierarchy before decoration** — one primary action per view; size, weight
   and contrast carry meaning; borders and shadows are quiet.
3. **Accessible by default** — WCAG AA contrast everywhere, a visible focus
   ring on every interactive element (`focus-visible:ring-*`), labels bound to
   inputs, full keyboard support, `prefers-reduced-motion` respected.
4. **Motion is feedback, not decoration** — 120–280ms, standard easing, only
   on opacity/transform; no bounces.
5. **Dark mode is a first-class theme** — every component must work in both
   themes via the `.dark` class (never assume light).
6. **Copy-in components** — components are owned by the consuming project; do
   not patch them with ad-hoc overrides, extend the system instead.

## Rules for AI agents

- When generating UI, compose from the component set first; build new
  charte ramps only when nothing fits.
- Buttons: exactly one `primary` per view. Destructive actions use
  `destructive`, never red text alone.
- Text: `text-foreground` for body, `text-muted-foreground` for secondary,
  never below 12px.
- Focus states are mandatory on every interactive element — never remove the
  outline without adding a `ring` equivalent.
- Icons: stroke icons (lucide), 16px inline / 20px standalone, stroke-width 2.
- Layout: 4px spacing rhythm (Tailwind spacing scale), page gutters ≥ 24px, cards use
  `--ds-radius-lg` and `border-border`.
- When reviewing UI, check: contrast, focus visibility, hierarchy (one
  primary), spacing rhythm, dark mode, empty/error/loading states.

## Typography

- Font stack: Inter → system-ui → sans-serif (`--ds-font-sans`); mono for code
  (`--ds-font-mono`).
- Scale (`--ds-font-size-*`): 12 / 14 / 16 / 18 / 20 / 24 / 30 / 36px.
  Body = 16px, secondary = 14px, page titles = 30–36px semibold.
- Weights: regular (400) for body, medium (500) for emphasis, semibold (600)
  for titles and buttons. Never use more than these.
- Line heights (`--ds-line-height-*`): tight 1.25 (headings), snug 1.375
  (large text), normal 1.5 (body), relaxed 1.625 (long-form).

## Components

Components live in [`components/ui/`](components/ui/) as copy-in Angular
standalone components and are distributed through the shadcn-style registry.
Naming: `Ds<Name>Component`, selector `ds-<name>` or attribute on native
elements (`button[dsButton]`). Variants are declared with
`class-variance-authority` (CVA).

| Component | Selectors | Notes |
| --------- | --------- | ----- |
| Button | `button[dsButton]`, `a[dsButton]` | variants: primary, secondary, outline, ghost, destructive; sizes: sm, md, lg, icon |
| Input | `input[dsInput]` | pairs with Label; `aria-invalid` → destructive ring |
| Label | `ds-label` | binds to inputs via `for` |
| Card | `ds-card` + `ds-card-header/title/description/content/footer` | `--ds-radius-lg`, `border-border` |
| Badge | `ds-badge` | variants: default, secondary, destructive, outline, success, warning |
| Alert | `ds-alert` | variants: default, info, success, warning, destructive |

## Motion

- Durations: fast 120ms (hover, focus), base 180ms (state changes), slow 280ms
  (panels, dialogs).
- Easing: `--ds-easing-standard` (default), `--ds-easing-emphasized` (enter).
- Animate only `opacity` and `transform`; wrap animations in
  `@media (prefers-reduced-motion: no-preference)` when non-essential.
